# Refined Emotions

Express yourself to your mates in R.E.P.O. with a six-expression wheel, matching arm poses and a front-facing self-view.

## Install

1. Click **Install with Mod Manager** on Thunderstore.
2. **Launch modded** from that profile.

Dependencies install automatically. The mod supplies its default controls on first launch; no config edits or previous setup are needed.

## Controls

- Hold **middle mouse** (the scroll-wheel button), point at an expression and release to play it for five seconds.
- Release in the center or press **Escape** to cancel.
- Hold **V** to see yourself from the front. Release to return to first person.
- The original number-key expressions also get the added arm poses.

The wheel pauses camera aiming while open. Arm poses yield to grabbing, map use, crawling and tumbling. Wheel and self-view controls are available during active play and cancel in menus, chat, loading, after death or when the game loses focus.

## Optional key bindings

Open **Mods → Refined Emotions → Emote wheel** to change **Button** or **Self-view**. Changes apply immediately. The defaults work without opening settings.

## Multiplayer

Everyone who wants to see the added arm poses needs the mod. Players without it still see the game's native eye expressions. Multiplayer pose reception has not yet been verified with a second player.

## Troubleshooting

Make sure you launched modded from the profile containing Refined Emotions. If the wheel still does not open during active play, include that profile's `BepInEx/LogOutput.log` in a bug report.

## Uninstall

Remove Refined Emotions in your mod manager with the game closed.
